① Daya Seimbang (ΣF = 0)

Objek tidak semestinya pegun! Objek boleh meluncur dengan halaju seragam (konstan) tanpa memerlukan sebarang daya paduan (Hukum Newton Pertama).

② Arah Daya vs Arah Gerakan

Daya paduan menentukan arah pecutan, bukan semestinya arah gerakan semasa! Semasa membrek, daya paduan bertentangan dengan halaju.

③ Penjumlahan Vektor Bukan Skalar

30 N + 40 N tidak sentiasa 70 N! Bergantung kepada sudut θ, paduan boleh bernilai antara 10 N (180°) hingga 70 N (0°), dan tepat 50 N pada 90°.

Pengiraan Langkah Demi Langkah

ΣF = ma
1. Leraian Komponen Daya
F₁x = 50.0 cos(30°) = 43.3 N
F₁y = 50.0 sin(30°) = 25.0 N
F₂x = 50.0 cos(-30°) = 43.3 N
F₂y = -50.0 sin(-30°) = -25.0 N
2. Hasil Tambah Vektor Komponen
ΣFx = 43.3 + 43.3 = 86.6 N
ΣFy = 25.0 + (-25.0) = 0.0 N
3. Magnitud Daya Paduan |ΣF|
|ΣF| = √(ΣFx² + ΣFy²) = 86.6 N
4. Pecutan Mengikut Hukum Newton II
a = |ΣF| / m = 86.6 / 20 = 4.33 m/s²
Arah pecutan θ = 0.0° (Menuju dermaga)
